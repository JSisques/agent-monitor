---
title: opencode-agent-monitor
description: OpenCode TUI plugin that shows what every subagent is doing, how long it has been running, and what it costs.
---

When an OpenCode agent delegates work, you see that a subagent was launched, but not what it is doing.
`opencode-agent-monitor` adds a per-subagent view to the OpenCode TUI:

- **Sidebar**: one line per running subagent: `agent · tool · time`.
- **Detail dialog**: every subagent launched in the session, including finished ones and nested subagents, with elapsed time, context usage, tokens and cost.

## How these docs are organized

- **Guides**: installation, usage and development.

- **Architecture**: how the packages fit together.
